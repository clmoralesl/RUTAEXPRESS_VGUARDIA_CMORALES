# Reglas del Proyecto RutaExpress

## Reglas de Git y Commits
1. **Idioma de los Commits**: Todos los mensajes de commit DEBEN redactarse obligatoriamente en **español**.
2. **Formato de Commit**: Seguir el estándar de Commits Convencionales cuando sea posible (ej: `feat: ...`, `fix: ...`, `docs: ...`, `chore: ...`).

## Estructura del Monorepo
1. **FRONTEND**: Código fuente de la aplicación Angular.
2. **BACKEND**: Microservicios en Spring Boot (`ms-rutaexpress-*`).
3. **DOCS**: Documentación del proyecto y guías de evaluación.
